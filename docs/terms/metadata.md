# Term: Metadata

Metadata is static or slowly changing reference information used to make tactical observations readable.

Examples in AURA-Sense include:

- system names
- ship/type labels
- group/category labels
- topology/reference labels

Metadata should be local-first where practical. AURA-Sense should not call live APIs repeatedly for static labels during normal HUD reporting.

Metadata is not tactical evidence by itself. It helps label observations; it does not prove intent, threat, or historical pattern.
