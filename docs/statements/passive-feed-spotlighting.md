# Statement: Passive Feed Spotlighting

Status: Active
Date: 2026-05-22

## Perspective

Broad passive feeds should be treated as temporary discovery streams, not automatic archives.

Receiving an event does not mean AURA-Sense must keep it.

## Guidance

AURA-Sense may inspect lightweight feed events and compare them against current tactical intent:

- current system
- session interests
- watched systems
- watched pilots/corporations/alliances
- active tactical search

If relevant, the system may expand, normalize, alert, or hand off. If not relevant, it should discard or retain only bounded diagnostics.

## Non-Goals

This statement does not authorize broad scraping, passive evidence hoarding, or persistent historical storage in AURA-Sense.

Persistent long-term memory belongs to AURA Atlas.

## Related Tenets

- Tactical Viewport First
- Transient By Default
- Respectful API Use
