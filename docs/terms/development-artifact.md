# Term: Development Artifact

A development artifact is a durable project record that preserves why the system moved in a certain direction.

AURA-Sense uses artifacts to prevent documentation drift, repeated rediscovery, and accidental scope expansion.

## Primary Artifacts

- current-state records
- audit and handover notes
- gap packets
- completed gap evidence
- roadmap milestones
- contracts and schemas
- failure records
- terms

## Rule

Create or update an artifact when future Dev or Overseer sessions would otherwise risk making the wrong tactical, architectural, or sequencing choice.
