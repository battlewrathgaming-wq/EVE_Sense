# Term: First Light

First Light is the first honest product-facing tactical viewport slice.

For AURA-Sense, First Light means the renderer presents backend-owned Combat Witness snapshot state with clear fresh, stale, empty, or unavailable language.

It proves the viewport can display observed tactical state without taking ownership of telemetry truth.

## What It Is

- narrow product surface
- Combat Witness snapshot presentation
- freshness-aware HUD state
- evidence that renderer boundaries are holding

## What It Is Not

First Light is not full tactical viewport readiness. It does not include Passive Telemetry, Threat Intel, pressure gauges, topology inference, recommendations, or Atlas-style persistence.
